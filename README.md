# Water Flow

Search any place on Earth, fly down to it from orbit, and trace where its water goes
across real terrain, live satellite imagery and a decade of archived captures.

![The globe](https://img.shields.io/badge/three.js-globe-4cc9f0) ![The map](https://img.shields.io/badge/maplibre-terrain-4cc9f0)

## What it does

- **Photoreal Earth.** A three.js globe textured with the NASA Blue Marble shaded-relief
  and bathymetry composite, VIIRS city lights on the night side, a masked ocean specular
  highlight, warm scattering through the terminator and an atmospheric limb.
- **Search anywhere.** Worldwide geocoding through OpenStreetMap Nominatim, with Photon
  as a second source when Nominatim rate-limits.
- **Descent.** Selecting a result swings the camera around the globe on a great circle
  and dives to the surface, then hands over to the map, which pulls back on its own to
  frame the whole catchment.
- **Water flow.** Every mapped channel around the site, drawn as a continuous stroke with
  a highlight travelling downstream along it. Channels come from the USGS National
  Hydrography Dataset inside the United States, which includes intermittent headwater
  streams that OpenStreetMap omits, and from OpenStreetMap everywhere else. NHD geometry
  is digitised in the downstream direction, so the animation runs the correct way.
- **Historical imagery that actually changes.** Esri publishes a World Imagery Wayback
  release every few weeks, but almost every release reuses the previous picture for any
  given place — which is why naively listing releases produces a row of buttons that all
  look identical. This app fingerprints one tile per candidate year at the target
  location and keeps only the releases whose imagery genuinely changed, so every year
  offered is a distinct capture. A blend slider crossfades today's imagery against the
  chosen year.
- **Site analysis.** A written reading of the measured layers — drainage density, built
  surface pressure, natural attenuation and what to look for across the imagery years.
  Generated by xAI Grok when a key is configured, and by a deterministic model over the
  same measurements when it is not.

## Running it

```bash
npm install
npm run dev -- --port 4317
```

Then open http://127.0.0.1:4317.

`npm install` runs `scripts/copy-maplibre-worker.mjs`, which copies maplibre-gl's web
worker and its shared chunk into `public/`. maplibre-gl locates its worker through
`import.meta.url`, which the Next bundler does not resolve to a servable path; without
the copy no worker starts and every layer that needs one — all GeoJSON plus the
elevation model — stays permanently blank.

### Optional: xAI

```bash
cp .env.example .env.local
# then set XAI_API_KEY
```

Without a key the analysis still renders, computed from the same measurements. With one,
it is written by Grok through `https://api.x.ai/v1/chat/completions`. Override the model
with `XAI_MODEL`.

## Data sources

| Layer | Source |
| --- | --- |
| Place search | OpenStreetMap Nominatim, Photon |
| Channel network | USGS National Hydrography Dataset (US), OpenStreetMap |
| Waterbodies, wetlands, buildings, roads | OpenStreetMap via Overpass |
| Elevation | USGS Elevation Point Query Service, Mapzen/AWS Terrain Tiles |
| Current imagery | Esri World Imagery |
| Archived imagery | Esri World Imagery Wayback |
| Globe textures | NASA GIBS Blue Marble and VIIRS City Lights |

Everything is public and keyless.

## Layout

```
src/
  app/
    api/analysis          xAI reading, with a measured-data fallback
    api/earth-texture     NASA GIBS globe textures
    api/geocode           Nominatim with a Photon fallback
    api/hydrology         NHD + Overpass channels, water, buildings, roads
    api/imagery/timeline  Wayback releases deduplicated to real captures
  components/
    globe/                three.js Earth, custom shaders, descent flight
    map/                  MapLibre terrain map, flow animation, imagery epochs
    panel/                Glass analysis panel
  lib/                    Geometry helpers, data collection, Wayback logic
scripts/
  copy-maplibre-worker.mjs  Required postinstall step
  smoke.mjs, map-smoke.mjs  Headless end-to-end checks
```

## Checks

```bash
npm run build
npx eslint src
node scripts/smoke.mjs      # full flow, reports console errors
node scripts/map-smoke.mjs  # map layers, flow animation, imagery switching
```

Both smoke scripts drive a headless Chrome against a running dev server.
